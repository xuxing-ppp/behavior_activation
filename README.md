## 为什么是微光

有时，我们知道自己想做什么，却很难迈出第一步。一个过大的计划、一张越积越长的待办清单，都可能让开始变得更费力。

微光围绕行为激活练习中的活动安排与行动回顾设计，把注意力放在一件具体、可行的小事上：

> 从「读完一本书」，到「翻开一页」。<br>
> 从「今天必须全部做完」，到「先试试这一小步」。

这里没有积分、连续打卡或必须达到的完成率。行动值得记录，休息与调整也有自己的位置。

## 你可以做什么

| 🌱 更容易开始 | 📝 更轻松记录 | 🍃 更温和调整 |
| :--- | :--- | :--- |
| 从当天计划中选择一件小事 | 一键记录「做到了」，支持撤销 | 把原计划缩小到 2、5 或 10 分钟 |
| 写下最小的第一步和它的意义 | 按需记录心情、愉悦感和成就感 | 暂缓、改期，让计划适应当前状态 |
| 没有头绪时，从活动建议中挑选 | 分数和文字反馈都可以留空 | 回顾近期行动，再安排想尝试的活动 |

### 今天 · 只看眼前这一小步

打开首页，就能看到一件可以尝试的行动。点击「开始这一步」，把注意力留给当前这件事；觉得困难时，随时调整。

### 安排 · 留有余地的计划

为活动选择日期、时长和类别，也可以写下第一步与个人意义。照顾自己、身体活动、人际连接、学习与事务、兴趣与愉悦，都可以成为计划的一部分。

### 回顾 · 观察，而不是评判

看看近期做过哪些事、留下了什么感受，观察自己的心情变化。从已有反馈中挑选想再做的活动，不要求每次行动都立刻带来好心情。

### 指南 · 需要时回来看看

随时查看练习方法、缩小步骤的例子，以及记录的备份与恢复入口。

## 开始使用

**第一次，只安排一件事就好。**

1. **选一件小事** — 喝一杯水、去窗边站一会儿，或写下你自己的计划。
2. **让它足够小** — 写清楚第一步，选择现在能接受的时长。
3. **按自己的节奏尝试** — 做到了就记录；不合适就缩小、暂缓或改到明天。
4. **想记录时再记录** — 留下一个心情分数或一句发现，之后再回来看看。

已部署的网站可以直接用浏览器访问，也可以下载本仓库后打开 `index.html`。无需注册，电脑和手机均可使用。

## 放进程序坞，让开始更方便

在 Mac 上，用 Safari 打开已部署的微光网站，选择「文件 → 添加到程序坞」，即可像 App 一样打开。网站已配置专属图标与独立窗口显示。

如果想手动选择图标，可使用 [高清 PNG](assets/icons/icon-1024.png) 或 [macOS 图标文件](assets/icons/weiguang.icns)。iPhone、iPad 也可以通过 Safari 的分享菜单添加到主屏幕。

> 网页 App 的记录可能与原浏览器窗口分开保存。已有记录时，先导出备份，再在新入口中导入。

## 记录与隐私

**你的活动与心情记录保存在当前浏览器中，不会由微光上传到服务器。**

- **无需账户**：开始练习前，不需要提供个人资料。
- **按需记录**：评分与反馈可选，未填写不会被当作零分。
- **草稿暂存**：未保存的心情草稿会在本次页面切换中保留；刷新或关闭后不保留。
- **随时备份**：在「指南 → 数据与隐私」中导出 JSON，也可以导入备份恢复记录。导入会替换当前记录。

不同设备、浏览器或网站地址之间不会自动同步。清理浏览器数据、使用无痕模式或更换访问地址，都可能使原有记录无法读取。建议定期导出备份，并妥善保管。
